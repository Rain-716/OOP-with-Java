### 实验二：带缓冲流与不带缓冲流性能比较

**实验思路**：

1. 编写两个 Java 程序：

   * **不带缓冲**：使用 `FileInputStream`/`FileOutputStream` 逐字节读写。
   * **带缓冲**：在上述流外层包裹 `BufferedInputStream`/`BufferedOutputStream`，并以更大块读取。

2. 在同一台机器上分别多次执行，记录读写时间（`System.nanoTime()`）。
3. 比较平均耗时差异。

**实验步骤**：

1. 准备一个大文件（10MB）。
2. 分别运行 `copyUnbuffered()` 和 `copyBuffered()` 5 次。
3. 取每组运行的平均值。

**实验结果**：

|类型|第一次|第二次|第三次|第四次|第五次|平均耗时（ms）|
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
|不带缓冲|42557|43594|43349|43647|42582|43145.8|
|带缓冲|10|12|11|11|11|11.0|

* 可以看到，带缓冲的读写速度显著高于不带缓冲。

### 实验三：`DataInputStream` 源码注释

**继承关系**：

```
java.lang.Object
 └─ java.io.InputStream
     └─ java.io.FilterInputStream
         └─ java.io.DataInputStream
```

**注释 `readBoolean()` 和 `readInt()` 实现**：

```java
// DataInputStream.java
public final boolean readBoolean() throws IOException {
    int ch = in.read();             // 从底层输入流读取一个字节
    if (ch < 0)                      // 如果返回值小于0，表示已到流末尾
        throw new EOFException();   // 抛出 EOFException
    return (ch != 0);               // 非零即 true，零即 false
}

public final int readInt() throws IOException {
    int ch1 = in.read();            // 读取第1个字节
    int ch2 = in.read();            // 读取第2个字节
    int ch3 = in.read();            // 读取第3个字节
    int ch4 = in.read();            // 读取第4个字节
    if ((ch1 | ch2 | ch3 | ch4) < 0) // 如果任一字节为 -1，表示流已结束
        throw new EOFException();   // 抛出 EOFException
    // 按大端顺序拼接成一个 int：
    // ch1<<24 | ch2<<16 | ch3<<8 | ch4
    return ((ch1 << 24) +
            (ch2 << 16) +
            (ch3 <<  8) +
             ch4);
}
```

**算法说明**：

* `readBoolean()`：直接读取一个字节，判断是否为 0；Java 无布尔字节类型，约定非零为 `true`。
* `readInt()`：依次读取 4 个字节。Java 网络字节序约定先高位后低位。将 4 个字节左移相应位数后相加，得到一个 32 位整数。
