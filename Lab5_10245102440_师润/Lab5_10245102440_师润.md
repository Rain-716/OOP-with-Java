## 1. `Name` 类定义

```java
public class Name {
    // 私有数据成员
    private String firstName;
    private String lastName;

    // 无参构造
    public Name() {
        this.firstName = "";
        this.lastName = "";
    }

    // 带参构造
    public Name(String firstName, String lastName) {
        this.firstName = firstName;
        this.lastName = lastName;
    }

    // 访问器与修改器
    public String getFirstName() {
        return firstName;
    }

    public void setFirstName(String firstName) {
        this.firstName = firstName;
    }

    public String getLastName() {
        return lastName;
    }

    public void setLastName(String lastName) {
        this.lastName = lastName;
    }

    // 转为 String
    @Override
    public String toString() {
        return firstName + " " + lastName;
    }

    // 测试 main
    public static void main(String[] args) {
        Name n = new Name("John", "Doe");
        System.out.println(n.getFirstName());
    }
}
```

## 2. `Person` 类定义

```java
public class Person {
    // 公开成员
    public Name name;
    public final int age;
    // 私有成员
    private String gender;

    // 无参构造
    public Person() {
        this.name = new Name();
        this.age = 0;

    }

    public Person(int age, String gender, Name name) {
```

## 3. 访问控制

1. **在 `Name` 类的主函数中是否能访问私有数据成员？**
   不能。即使在同一个类的 `static main` 方法里，也只能通过公有方法访问私有成员。

2. **在 `Person` 类中（如 `chatWith` 方法）能否直接访问 `name` 对象的私有成员？**
   不能。即便 `name` 是 `public` 的对象引用，其内部私有成员仍须通过 `getFirstName()`/`getLastName()` 访问。

3. **若将 `Name` 的字段改为包访问（default），上述在 `Person` 类能否访问？**

   * 如果 `Person` 和 `Name` 在同一个包下，则可以直接访问包访问字段。
   * 若在不同包，则仍然不能访问。

4. **若将 `Name` 与 `Person` 分在不同包，下列情况如何？**

   * `Name` 字段为 `private`：无论同包与否，都无法直接访问。
   * `Name` 字段为包访问：同包可访问；不同包不可访问。
   * `Name` 字段为 `public`：所有包都可访问。

## 8. `Discussion` 类

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Random;

public class Discussion {
    private List<Person> members = new ArrayList<>();
    private Random rand = new Random();

    public Discussion(int numStudents, int numTeachers) {
        // 强制生成指定数量
        for (int i = 0; i < numStudents; i++)
            members.add(new Student(18 + i, "female", new Name("Stu", String.valueOf(i))));
        for (int i = 0; i < numTeachers; i++)
            members.add(new Teacher(30 + i, "male", new Name("Tch", String.valueOf(i))));
    }

    public void broadcast() {
        int idx = rand.nextInt(members.size());
        Person sender = members.get(idx);
        for (Person p : members) {
            if (p != sender) {
                sender.chatWith(p, "Hello everyone!");
            }
        }
    }

    public static void main(String[] args) {
        Discussion d = new Discussion(2, 2);
        d.broadcast();
    }
}
```

## 10. 返回值类型

```java
class Sup {
    // A 与 B 相同时
    public String f() {
        return "Sup";
    }
}

class SubSame extends Sup {
    @Override
    public String f() {
        return "SubSame";
    }
}

class SubArray extends Sup {
    // 返回类型不同：Sup 返回 String，B 为 int → 编译错误
    // public int f() { return 1; }
}

class SubCovariant extends Sup {
    // B 是 A（String）的子类？String 无子类 → 也会报错
    // 只有当 A、B 为类时且 B 是 A 的子类才合法
}

// Covariant 合法示例：
class A {}
class B extends A {}
class Super2 {
    public A f() { return new A(); }
}
class Sub2 extends Super2 {
    @Override
    public B f() { return new B(); }  // 协变返回类型，合法
}
```

* **若 A、B 相同**：正常重写，可运行。
* **若 A 为数组，B 为 int**：编译错误，返回类型不兼容。
* **若 B 是 A 的子类**：Java 允许返回类型协变，编译并运行通过。

## 二、`Circuit` 类的基本实现

```java
public abstract class Circuit {
    // 返回本网络的等效电阻
    public abstract double resistance();

    // 解析字符串表达式，构造对应的 Circuit 对象树。
    public static Circuit parse(String expr) {
        expr = expr.trim();
        // 如果不是以 '(' 开头，则认为是单个电阻值
        if (!expr.startsWith("(")) {
            double val = Double.parseDouble(expr);
            return new Resistor(val);
        }
        // 去掉最外层括号
        String inside = expr.substring(1, expr.length() - 1).trim();

        // 第一个字符即运算符：'-' 或 '/'
        char op = inside.charAt(0);
        // 跳过 "op,"，从索引2开始解析子表达式
        String rest = inside.substring(2).trim();

        // 找到分隔左右子表达式的那个逗号
        int depth = 0;
        int splitPos = -1;
        for (int i = 0; i < rest.length(); i++) {
            char c = rest.charAt(i);
            if (c == '(') depth++;
            else if (c == ')') depth--;
            else if (c == ',' && depth == 0) {
                splitPos = i;
                break;
            }
        }
        if (splitPos < 0) {
            throw new IllegalArgumentException("无法解析表达式: " + expr);
        }

        // 左子表达式：[0, splitPos)，右子表达式：(splitPos+1, end]
        String leftExpr  = rest.substring(0, splitPos).trim();
        String rightExpr = rest.substring(splitPos + 1).trim();

        Circuit left  = parse(leftExpr);
        Circuit right = parse(rightExpr);
        if (op == '-') {
            return new Series(left, right);
        } else if (op == '/') {
            return new Parallel(left, right);
        } else {
            throw new IllegalArgumentException("未知运算符: " + op);
        }
    }
}
```

**示例调用**

```java
// 测试演示
public static void main(String[] args) {
    String[] tests = {
        "(-,3,5)",
        "(/,3,5)",
        "(-,(-,3,5),7)",
        "(-, (/, (/,4,8), 5), 3)"
    };
    double Vbat = 12.0;

    for (String expr : tests) {
        Circuit c = Circuit.parse(expr);
        System.out.println("表达式: " + expr);
        System.out.printf("  等效电阻 R = %.3f Ω%n", c.resistance());
        System.out.printf("  在 %.1f V 下总电流 I = %.3f A%n", Vbat, c.current(Vbat));
        System.out.println("  详细分布：");
        c.printVoltageCurrent(Vbat);
        System.out.println("-------------------------------");
    }
}
```

## 三、扩展：给定电源电压，计算电压分布与电流

1. **在 `Circuit` 中新增两个抽象方法**

   ```java
   // 在两端施加电压，返回通过本网络的电流
    public double current(double voltage) {
        return voltage / resistance();
    }

    // 在两端施加电压 voltage 时，打印本节点及子节点的电压、电流
    public abstract void printVoltageCurrent(double voltage);
   ```

2. **各子类实现**

   * **Resistor**

    ```java
    class Resistor extends Circuit {
        private final double r;
        public Resistor(double r) { this.r = r; }
        @Override
        public double resistance() { return r; }

        @Override
        public void printVoltageCurrent(double voltage) {
            double i = current(voltage);
            System.out.printf("    Resistor %.3fΩ: U=%.3fV, I=%.3fA%n", r, voltage, i);
        }
    }
    ```

   * **Series**（串联电路）

    ```java
    class Series extends Circuit {
        private final Circuit a, b;
        public Series(Circuit a, Circuit b) { this.a = a; this.b = b; }

        @Override
        public double resistance() {
            return a.resistance() + b.resistance();
        }

        @Override
        public void printVoltageCurrent(double voltage) {
            double i = current(voltage);
            System.out.printf("  Series: U_total=%.3fV, I=%.3fA%n", voltage, i);
            double ua = a.resistance() * i;
            double ub = b.resistance() * i;
            a.printVoltageCurrent(ua);
            b.printVoltageCurrent(ub);
        }
    }
    ```

   * **Parallel**（并联电路）

    ```java
    class Parallel extends Circuit {
        private final Circuit a, b;
        public Parallel(Circuit a, Circuit b) { this.a = a; this.b = b; }

        @Override
        public double resistance() {
            double r1 = a.resistance(), r2 = b.resistance();
            return 1.0 / (1.0/r1 + 1.0/r2);
        }

        @Override
        public void printVoltageCurrent(double voltage) {
            double itot = current(voltage);
            System.out.printf("  Parallel: U=%.3fV, I_total=%.3fA%n", voltage, itot);
            a.printVoltageCurrent(voltage);
            b.printVoltageCurrent(voltage);
        }
    }
    ```
